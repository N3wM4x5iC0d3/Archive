# 压缩包密码破解

一款界面美观的压缩包密码恢复工具，支持 ZIP / 7Z / RAR 多种格式，提供从「已知密码」到「未知密码」的全套破解方案。

## 功能
- **支持的格式**：ZIP（含 AES-256 加密）、7Z、RAR
- **多种破解模式**：
  - 直接解密：已知密码直接解压
  - 暴力破解：自定义字符集与长度
  - 字典攻击：从字典文件逐行尝试
  - 掩码攻击：用 `?l ?u ?d ?s ?a` 等占位符精确约束
  - 混合攻击：字典 + 掩码（前缀 / 后缀）
  - 数字序列：纯数字范围
  - 组合攻击：两个字典两两拼接
  - 规则攻击：对字典应用变换规则
  - 明文攻击：基于 bkcrack 的 ZIP 已知明文攻击
  - 密钥解密：使用已恢复的 ZIP 内部密钥直接解锁
- **多进程并行**：可手动指定 CPU 核心数，充分利用多核加速
- **现代化界面**：基于 Edge WebView2，自动跟随系统亮 / 暗主题
- **贴心体验**：窗口位置记忆、透明度调节、原生文件对话框
- **中文友好**：自动修复 ZIP 中文文件名解压乱码，正常显示中文名
- **温馨提示**：可能会被系统识别成病毒关掉杀毒软件就可以了

## 优点
- **界面美观**：基于 WebView2 的现代界面，比传统 Tk / 控制台更顺眼
- **模式齐全**：无论你记得部分密码、有字典、知道明文，还是只能硬暴力，都能找到对应方案
- **速度快**：多进程充分利用多核 CPU，破解效率更高
- **开箱即用**：首次运行自动检测并引导安装缺失依赖（WebView2 运行时、bkcrack、UnRAR 等）
- **中文无乱码**：专门针对中文 ZIP 文件名做了编码修复，解压文件名正确显示
- **偏好记忆**：窗口位置、主题、核心数等设置自动保存，下次打开无需重设
- **轻量单文件**：可打包为单个 exe，便携、随开随用
